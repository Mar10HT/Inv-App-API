Tablas nuevas
Role
  • id, name (unique), displayName, description
  • isSystem — no se puede eliminar desde UI
  • 5 roles iniciales migrados del enum
Permission
  • id, key (unique), module, action, description
  • Formato key: modulo:accion
  • 63 permisos — seeded, no editables desde UI
RolePermission
  • Tabla de unión M:N entre Role y Permission
  • unique(roleId, permissionId)
  • Invalida cache al modificar

User
  • roleId String? FK → Role
  • permissionsVersion Int @default(0)
UserWarehouse
  • roleId String? FK → Role (multi-rol futuro)
Eliminado en Fase 7 (post-estabilización)
Enum UserRole
  • SYSTEM_ADMIN, WAREHOUSE_MANAGER, USER, VIEWER, EXTERNAL
  • Reemplazado por tabla Role
User.role (campo)
  • Se elimina cuando todos los usuarios tengan roleId
  • Requiere migración completa de datos
Roles iniciales (migrados del enum)
5 roles isSystem — no eliminables desde UI
  • SYSTEM_ADMIN → "Administrador del Sistema" — bypass implícito
  • WAREHOUSE_MANAGER → "Gerente de Almacén"
  • USER → "Operador"
  • VIEWER → "Observador"
  • EXTERNAL → "Externo" — solo inventory:view_assigned + alerts:view
